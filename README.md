# Clawd Pet - 像素小螃蟹踩键盘桌宠

一个轻量级、纯本地离线的跨平台桌面宠物（支持 Windows 与 macOS）。你在任何软件里打字时，屏幕角落里的小螃蟹都会同步在像素机械键盘上歪歪斜斜地蹦跳踩键。

## 安装说明

* **Windows**：在 Releases 页面下载 `.exe` 安装程序（推荐）或 `.msi` 安装包直接运行即可，支持覆盖安装更新。如首次打开弹出 Windows 安全提示，点击「更多信息」->「仍要运行」即可。
* **macOS (Apple Silicon)**：下载 `.dmg` 打开后拖入「应用程序」。由于需要监听全局按键，首次运行请在「系统设置 -> 隐私与安全性 -> 辅助功能 / 输入监控」中勾选放行本应用。

## 主要功能

* **实时全局同步 & 踩键独立音量**：打字时自动踩踏对应键区，支持转身、连击 `> <` 狂飙，急停折返还有概率脚滑摔倒；支持奶油、复古、樱粉、抹茶、暗夜 5 套键盘配色，与柔顺、青轴、麻将、木鱼（`+1`）4 种机械手感音效，并可在菜单内独立调节踩键音量。
* **丰富鼠标互动 & 系统托盘**：无操作时眼睛全程跟随鼠标（可开启「害羞躲鼠标」与「躲键盘后面偷看」）；短按戳一戳、长按左右搓摸头（**猫耳皮肤摸头会发出真实猫咪呼噜声**）、长按拎起来晃悠。透明区域自动穿透不挡任务栏，支持系统托盘图标与右键快捷菜单一键切换锁定/音效。
* **9 套皮肤 & 6 款单选配饰**：原版小螃蟹、猫耳喵咪、魔法师、经典女仆、纯围裙、睡衣小兔、小飞象章鱼，以及全新 **小天使**（悬浮光环 + 会扇动的像素白羽翅膀）与 **小恶魔**（像素小角 + 蝠翼小翅膀 + 摇摆箭尾）；配饰支持像素墨镜、像素耳机、**圆框眼镜**、头顶小橘子、米妮风大蝴蝶结、贴脖大金链。
* **桌面彩蛋 & 窗口场景感应（Windows）**：支持复制叼纸条 / 粘贴吐纸条、低电量抱插头 / 充电复活、放歌自动戴耳机摇晃；开启「窗口场景感应」后，会根据当前正在看剧、码字、打游戏（抱红蓝 Switch）或画画（全键盘变数位板、举笔同步描线）自动切换专属桌面动作。
* **12 种像素零食 & 御三家玩具盒**：含珍珠奶茶、小蛋糕、甜甜圈、寿司、冰美式续命以及 `X-X` 黑暗料理惊喜（毒蘑菇 / 魔鬼辣椒）；可丢出 OpenAI / Gemini / Claude 球球抛接炫耀，或让小螃蟹踩着球球在键盘上滚来滚去。
* **四页签清爽菜单 & 贴心陪伴**：菜单重构为「装扮 / 互动 / 陪伴 / 设置」四个分类页签，状态高亮更清晰；内置头顶气泡说话（支持自定义语录）、15 / 25 / 45 分钟番茄钟、45 分钟喝水举杯提醒、可开关的「满千键撒花」与「深夜被窝提醒」（1 分钟无操作自动打盹）。
