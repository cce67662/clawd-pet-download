# Clawd Pet - 像素小螃蟹踩键盘桌宠

一个轻量级、纯本地离线的跨平台桌面宠物（支持 Windows 与 macOS）。你在任何软件里打字时，屏幕角落里的小螃蟹都会同步在像素机械键盘上歪歪斜斜地蹦跳踩键。

> **立即下载最新版本（v1.3.0）**：[点击前往 Releases 下载页面](https://github.com/cce67662/clawd-pet-download/releases/latest)

---

## 安装说明

* **Windows**：在 Releases 页面下载 `.exe` 安装程序（推荐）或 `.msi` 安装包直接运行即可，支持覆盖安装更新。如首次打开弹出 Windows 安全提示，点击「更多信息」->「仍要运行」即可。
* **macOS (Apple Silicon)**：下载 `.dmg` 打开后拖入「应用程序」。由于需要监听全局按键，首次运行请在「系统设置 -> 隐私与安全性 -> 辅助功能 / 输入监控」中勾选放行本应用。

---

## 主要功能

* **实时全局同步**：打字时自动踩踏对应键区，支持转身、连击 `> <` 狂飙，急停折返还有概率脚滑摔倒；支持奶油、复古、樱粉、抹茶、暗夜 5 套键盘配色，与柔顺、青轴、麻将、木鱼（`+1`）4 种机械手感音效。
* **丰富鼠标互动 & 透明穿透**：无操作时眼睛会全程跟随鼠标；短按戳一戳、长按左右搓摸头、长按拎起来晃悠。透明区域自动穿透不挡任务栏，支持一键「锁定防误触」。
* **7 套皮肤 & 5 款单选配饰**：原版小螃蟹、猫耳喵咪、魔法师、经典女仆、纯围裙、睡衣小兔、**小飞象章鱼**；配饰支持像素墨镜、像素耳机、头顶小橘子、米妮风大蝴蝶结、贴脖大金链。
* **听歌自动摇摆（Windows）**：播放音乐时自动戴上耳机，闭着 `U  U` 眼陶醉摇晃，还会间歇性手舞足蹈、冒像素音符。
* **12 种像素零食 & 御三家玩具盒**：含珍珠奶茶、小蛋糕、甜甜圈、寿司、冰美式续命以及 `X-X` 黑暗料理惊喜（毒蘑菇 / 魔鬼辣椒）；可丢出 OpenAI / Gemini / Claude 球球抛接炫耀，或让小螃蟹踩着球球在键盘上滚来滚去。
* **贴心陪伴小工具**：头顶气泡说话（支持自定义语录）、15 / 25 / 45 分钟番茄钟、45 分钟喝水举杯提醒、可开关的「满千键撒花」庆祝，以及可开关的「深夜被窝抱枕头提醒」。
